# GameCube — эмулятор Nintendo GameCube для PS4

Бесплатный проект порта Dolphin для PlayStation 4, ориентированный на PS4 Pro с HEN.

> **Статус: рабочая версия.** По подтверждению автора проекта от 1 ноября 2026 года, эмулятор уже работает. Независимое тестирование на консоли в рамках этого репозитория не заявляется.

## О проекте

Цель проекта — дать владельцам совместимых консолей PS4 возможность запускать игры Nintendo GameCube с помощью адаптированной версии DolphinPS4.

Проект распространяется бесплатно. Репозиторий не содержит коммерческих игровых образов: пользователи должны самостоятельно использовать законно полученные копии игр.

## Возможности и совместимость

- Целевая платформа: PlayStation 4 / PS4 Pro с HEN.
- Основа: DolphinPS4 и исходный код Dolphin Emulator.
- Совместимость конкретных игр и производительность зависят от игры, настроек и модели консоли.
- Список проверенных игр, режимов управления и известных ограничений будет пополняться по результатам тестов.

## Получение и установка

Исходный код и история изменений доступны в этом репозитории. Устанавливаемый PKG следует публиковать в разделе **Releases** после проверки файла и контрольной суммы. Если в Releases пока нет опубликованного пакета, значит прямая загрузка PKG ещё не размещена.

1. Откройте раздел [Releases](https://github.com/sultanxan222222-sudo/GameCube/releases).
2. Скачайте PKG из последнего опубликованного релиза, если он там доступен.
3. Установите пакет на совместимую PS4 с HEN обычным для вашей системы способом.
4. Используйте собственные законно полученные игровые образы.
