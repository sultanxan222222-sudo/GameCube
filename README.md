# GameCube — PS4 Pro

Проект отдельного порта эмулятора Nintendo GameCube для PlayStation 4 Pro.

> Статус: начальная настройка репозитория. Рабочий эмулятор и устанавливаемый PKG пока не собраны.

## Цель

Подготовить порт на основе открытого исходного кода Dolphin Emulator, с адаптацией под среду PS4 и проверкой совместимости на реальном оборудовании.

## Приоритеты

1. Изучить исходный код Dolphin и лицензионные требования.
2. Проверить доступность подходящего PS4 homebrew toolchain и системных библиотек.
3. Создать отдельную PS4-платформенную сборочную конфигурацию.
4. Реализовать запуск приложения и базовое меню.
5. Адаптировать графический и аудиобэкенды к доступным возможностям PS4.
6. Добавить управление DualShock 4, выбор игр с USB и сохранения.
7. Собрать и проверить PKG на целевой консоли.

## Важные ограничения

- Репозиторий не содержит образов коммерческих игр, BIOS или иных защищённых игровых данных.
- Создание README не означает, что эмулятор уже портирован или что PKG готов.
- Совместимость и производительность должны подтверждаться сборкой и тестами на PS4 Pro.
